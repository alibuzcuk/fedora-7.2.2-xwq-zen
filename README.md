# Fedora 7.2.2-xwq-zen+ Kernel Config

Intel i3-5005U / HD 5500 ve benzer donanımlar için özel olarak optimize edilmiş low-latency Linux kernel konfigürasyonu.

## Öne Çıkan Özellikler
- **CONFIG_HZ=1000**: Düşük girdi gecikmesi ve kararlı FPS.
- **PREEMPT**: Maksimum sistem tepkiselliği.
- **Zswap**: 8GB RAM ve altı sistemlerde akıcı bellek yönetimi.

Minecraft ve genel Linux gaming performansını artırmak amacıyla derlenmiştir.
